# Умный зайчик

Пауза Марио сохраняет заработанное время на сервере; START продолжает с остатка, без выдачи новых минут. Подробности и проверки: [MARIO.md](MARIO.md).

Внешний доступ с общим прогрессом готовится через отдельный HTTPS-туннель к той же базе Lenovo. GitHub Pages публикует только папку docs: она открывает единую HTTPS-версию игры из docs/game.json. Пароли, сессии, прогресс, музыка, наклейки и ROM не загружаются на GitHub. Локальные копии учебных профилей не создаются.

Для внешнего слушателя используется тот же tool/bunny-server.py с параметрами --bind 127.0.0.1 --port 8098 --public-origin https://HOSTNAME. Он разрешает только указанный HTTPS origin, выдаёт Secure/HttpOnly/SameSite=Strict cookie и требует вход для всех assets. Первоначальная настройка родителя доступна только через прежнюю домашнюю службу. Домашний порт 8097 продолжает работать с той же SQLite-базой. Проверка: python3 verify-public.py (два слушателя, общие результаты/альбом, повторная отправка, доступ к приватным файлам, cookie, origin, выход).

tool/install-tunnel.py устанавливает проверенные по официальному SHA-256 бинарники Tailscale в отдельную службу smart-bunny-tunnel внутри контейнера игры. Она использует userspace networking без TUN, маршрутизации домашней сети и изменения DNS; Funnel отдельно включается только после входа владельца и настройки защищённого слушателя. tool/enable-public.py подготавливает loopback-службу smart-bunny-public для конкретного HTTPS-адреса. Установщики не запускаются автоматически при синхронизации кода с GitHub.

HTML/CSS/JavaScript-игра с шестью прежними режимами и русским языком для 1–4 классов. Два оформления и анимации зайчика сохранены.

## Запуск

Из папки проекта: `python3 -m http.server 8097 --bind 127.0.0.1`.
Открыть http://127.0.0.1:8097/ . Нужен HTTP для загрузки WAV и JSON; file:// не поддерживается. После обновления перезагрузите страницу по завершении текущего раунда.

## Русский язык

48 тем, 1767 вопросов. Реестр и справочные источники: [CURRICULUM.md](CURRICULUM.md).

Класс → вид тренировки:
- По темам → направление → конкретная тема.
- Смешанная тренировка: темы выбранного класса чередуются, количество вопросов по представленным темам различается максимум на один. Короткий раунд может не охватить все темы класса.
- Работа над ошибками: новые примеры из тем, где были ошибки. Счётчик трудностей увеличивается при неверной первой попытке и уменьшается при верном первом ответе в этом режиме. Это простая модель повторения, не диагностика освоения учебной программы. Когда трудностей нет, кнопка недоступна.

Длина: 10, 50 или 100 вопросов. Класс, длина, переключатель оценки 1 класса, история показанных примеров и трудные темы сохраняются в localStorage. При блокировке хранилища состояние действует только до закрытия/перезагрузки страницы. История содержит и выбранные примеры незавершённых раундов.

Наборы сначала используют не показанные в текущем цикле вопросы. После исчерпания банка начинается новый цикл; в отдельных темах с 30 примерами раунд 100 неизбежно содержит повторы. Порядок ответов перемешивается.

Баллы — только за первую попытку. При ошибке показываются правильный ответ, разбор именно этого примера и общее правило. Они остаются до кнопки «Продолжить». Первая ошибка ведёт к повтору того же задания без балла, вторая — к следующему после подтверждения. Исправления учитываются отдельно. Скорость ответа и чтения не оценивается.

Оценка по доле верных первых ответов: от 90% — 5, от 70% — 4, от 50% — 3, ниже 50% — 2. В 1 классе по умолчанию звёзды и поддержка, числовую оценку можно включить. Во 2–4 классах оценка включена всегда.

Итог включает результат по каждой участвовавшей теме и кнопки повторения трудных тем. Результат из одного вопроса по теме не означает надёжную оценку её освоения. «Играть ещё» сохраняет тип тренировки и длину; если ошибки уже отработаны, повтор работы над ошибками возвращает к выбору тренировок.

Новые направления: звуки и буквы, слоги/ударение/перенос, словарные слова, значения и родственные слова, части речи, формы слов, состав слова, предложение и текст, понимание прочитанного, речевой этикет. Задания на порядок представлены выбором готового правильного варианта; свободный ввод и перетаскивание не добавлялись.

## Математика и запоминание

Правила не менялись. Запоминание: 50 заданий, три цифры на 1,5 секунды, один балл за первую попытку; после ошибки повтор тех же цифр, вторая попытка без балла. Остальные пять прежних игр: по 10 вопросов, один балл за правильный ответ. Настройки сохраняют задание, попытку и ожидание подтверждения. legacy/calculator_original.html — отдельный старый калькулятор.

## Аудио

WAV из assets/audio/music декодируются и кешируются Web Audio. Циклы читаются из loops.json как исходные sample offsets / 44100, независимо от частоты AudioContext. Нативный loop без таймеров, переход между треками 40 мс. При показе цифр музыка приглушается.

Автовыбор: память — Underwater, сравнение — Underground, закономерность — Castle, сложение — Overworld, умножение — Starman, деление — Underground, русский язык — Underwater. Ручной выбор, автоматический режим, раздельная громкость и отключение сохранены.

Победа отменяет поздние загрузки и останавливает текущие/затухающие музыкальные источники. Оригинальная фанфара звучит целиком через Web Audio. Меню и новая игра не прерывают её; новая музыка ждёт окончания. Явный mute останавливает всё. Остальные эффекты используют HTMLAudioElement.

Исходный NSF и все WAV не менялись. Точность NES-эмуляции и ограничения стыков описаны в assets/audio/music/CONVERSION.md. Публикация не выполнялась.

## Проверки

`node verify.cjs`: данные всех 48 тем, 10/50/100, границы оценок, первые/вторые ответы, подтверждение без таймера, настройки, изоляция классов, смена наборов, сохранение истории, смешанные раунды всех четырёх классов, равномерность/чередование тем, отчёт по темам, сохранение трудностей, новые примеры при повторении, завершение работы над ошибками. Также прежние математические сценарии.

`node verify-audio.cjs`: отложенная загрузка, отмена после меню/победы/смены режима, циклы 44100 в AudioContext 48000, громкость, ручной выбор, фанфара, mute, ошибки сети.

В браузере Mac пройдены смешанный раунд 4 класса с ошибками (4 первых ответа + 6 исправлений) и работа над ними на новых примерах (10/10). Проверены чтение, отчёт по темам, переход к повторению и очистка трудностей после правильных ответов. Ошибок консоли нет. Реальный iPhone Safari в этом этапе недоступен; автоматические проверки звука дополняются прослушиванием на устройстве.

## Профили и наклейки

Откройте игру по домашнему адресу Lenovo и войдите с личным логином и паролем. При первом запуске родитель вводит одноразовый код из файла рядом с базой прогресса (progress.setup-code), выбирает свой существующий профиль или создаёт новый, затем назначает себе логин и пароль. В родительском кабинете можно привязать логины к прежним детским профилям, создать нового игрока или сбросить забытый пароль. Прежний прогресс и наклейки остаются в тех же профилях.

Доступные классы русского языка задаются в профиле игрока (schoolClasses). Выбор класса, отдельные и смешанные тренировки, работа над ошибками и русские задания миссий используют только доступные классы. Списки пройденных тем сохраняются отдельно и продолжают ограничивать смешанные задания 2-го и 4-го класса.

Сервер разрешает чтение и изменение прогресса только владельцу действующей сессии. Сброс пароля завершает все сессии соответствующего игрока. «Выйти» отзывает текущую сессию. Обычная сессия действует до 12 часов, с флажком «Запомнить вход» — до 30 дней. Пароли от 8 символов хешируются PBKDF2-HMAC-SHA256 с индивидуальной солью и 600000 итераций. Пять неудачных попыток блокируют вход на 5 минут. Cookie сессии имеет HttpOnly и SameSite=Strict. На текущем домашнем HTTP-адресе транспорт остаётся незашифрованным.

Завершённые раунды, пройденные темы, ошибки и наклейки хранятся на Lenovo. История отдельных вопросов и очередь ещё не отправленных результатов хранятся в браузере с привязкой к игроку. После смены аккаунта очередь отправляет только результаты вошедшего игрока. На статическом хостинге экран входа предлагает открыть домашнюю версию.

Альбом — одно большое поле с круглыми наклейками, как поле значков Apple Watch. Свайп или перетаскивание мышью двигает обзор в любом направлении, даже если жест начат на наклейке. Колесо мыши/трекпад и стрелки при фокусе на поле тоже двигают обзор. Два пальца плавно меняют масштаб всего поля от 50% до 200% с сохранением точки между пальцами. Кнопки «− / +» меняют масштаб шагом 25 процентных пунктов; Ctrl + колесо/жест трекпада масштабирует около указателя. «В центр» возвращает к коллекции и масштабу 100%. При касании вторым пальцем предварительный перенос наклейки отменяется; после отпускания одного пальца можно продолжить двигать поле другим без скачка. Касание наклейки открывает её крупно; удержание 450 мс с последующим перетаскиванием перемещает только её. Стрелки при фокусе на самой наклейке также меняют её положение. «Отменить» возвращает до 30 последних перемещений текущего сеанса.

Все полученные наклейки, в том числе с прежних страниц и ещё не приклеенные, отображаются на едином поле. Новые награды получают постоянные места в сетке и не сдвигают прежние. Ползунки размера и поворота, добавление и выбор страниц убраны. Старые страницы, координаты и параметры сохранены в профиле для совместимости; их не нужно переносить вручную. При первом перемещении сохраняются координаты нового поля, а отмена восстанавливает исходное состояние без утраты награды.

Масштаб, положение обзора и наклеек сохраняются на Lenovo отдельно для каждого игрока. Очередь браузера восстанавливает изменения после потери связи и перезагрузки. Кнопка «Рассмотреть» показывает крупное изображение и условие получения закрытых наград в коллекциях. Учебные результаты, цены, миссии и правила выдачи наград не меняются.

Персонажи и предметы коллекций выдаются только за достижения. Старые запросы обмена монет на наклейки не списывают баланс и не выдают награды. Все уже полученные наклейки и их координаты сохраняются.

Миссии делятся на три категории: обычные (математика/русский с прежней стоимостью до 7), редкие (остальные математические/русские персонажи), особые (смешанные миссии). Стандартные условия: обычная — 16 из 20 с первой попытки; редкий герой — две миссии по разным темам, каждая 17 из 20; особый — 27 из 30 смешанных заданий. Для профиля с `stickerPolicy=junior-v1` (Юля): обычная — 7 из 10, редкий — две разные темы по 7 из 10, особый — 8 из 10; исправления второй попытки учитываются только для награды. Учебные баллы остаются за первую попытку. Для русского используются только пройденные темы разрешённых классов. Этапы редких героев сохраняются на сервере; повтор той же темы и неуспешная попытка не стирают и не удваивают этап. Старая вкладка может отправить учебный результат, но не обойти новые условия. Звезда по-прежнему выдаётся за три решённых задания работы над ошибками, включая исправления.

Монеты сохраняются и используются для оформления альбома: «Горошек» — 5, «Звёздочки» — 8, «Космос» — 10. Покупка каждого фона оплачивается один раз, дальнейшее переключение бесплатно; обычный фон всегда доступен. Оформление меняет только фон, не координаты, масштаб или список наклеек. За обычный завершённый раунд — 1 монета, за успешную миссию дня — 2 один раз за московский календарный день. Изображения остаются приватными на Lenovo.

Проверки: `python3 verify-achievements.py`, `node verify-achievements.cjs`, `python3 tool/verify-stickers.py`.

Для проверки профилей на компьютере запустите из папки проекта:

```sh
python3 tool/bunny-server.py --directory . --database ../smart-bunny-local/progress.sqlite
```

Профили доступны по адресу http://127.0.0.1:8097/ . Файл SQLite должен находиться вне папки сайта. Родитель сначала настраивает вход, затем выдаёт каждому игроку личные данные. Первоначальный код хранится рядом с SQLite, вне папки сайта. Сервер и база рассчитаны на домашнюю сеть.

Проверка доступа выполняется командой python3 verify-auth.py. Она использует отдельную временную базу и HTTP-сервер, проверяет миграцию прежних профилей, изоляцию, cookie, сброс пароля, выход, срок сессии, повторную отправку наград и ограничение попыток.

## Просмотр уровня Super Mario Bros. через эмулятор

В домашней версии выберите «Марио» и нажмите «Настоящий уровень». Браузер загрузит файл Super Mario Bros. для NES с домашнего сервера (`assets/emulation/smb-world.nes`). Если файл недоступен или страница открыта с диска, можно выбрать локальный файл Super Mario Bros. (World/USA–Japan, формат `.nes`). Он читается в память браузера.

Рядом с кнопкой можно выбрать 1-1, 1-2 или 1-3. Для запуска нужен локальный файл `assets/emulation/jsnes-2.1.0.min.js` ([JSNES 2.1.0](https://github.com/bfirsh/jsnes), Apache 2.0). Перед первым показом каждого уровня браузер проверяет маршрут на загруженном ROM. После каждого задания Марио проходит часть маршрута и достигает флага после последнего. ROM и проверенные маршруты переиспользуются в текущей вкладке.

Эффекты уровня воспроизводит звуковой процессор NES в JSNES. Дорожка NES приглушена, а фоновая музыка выбирается настройками «Умного зайчика». На звуки уровня действует регулятор «Эффекты» и общая кнопка отключения звука.


## Ручная игра в Марио

В родительском профиле доступен отдельный пункт «Играть в Марио». Детям он не показывается: каждый новый полностью завершённый учебный раунд даёт один запуск на 10 минут. Кнопка награды появляется после сохранения результата; неиспользованные запуски и действующий доступ доступны также через «Награда за задания». Старые раунды не начисляются задним числом. Повторная отправка одного результата и повторный запуск страницы не дают лишних минут. Пауза и закрытие вкладки не останавливают 10-минутный срок с момента запуска.

Сервер проверяет профиль, родительскую роль, заработанный запуск и срок доступа. При переносе действующей сессии на другое устройство время не продлевается, предыдущая игровая сессия перестаёт подтверждаться. Без связи с Lenovo ручная игра приостанавливается. Доступ хранится в отдельных таблицах mario_tickets и mario_sessions; учебные баллы, монеты, награды и положения наклеек не меняются от ручной игры.

Экран поддерживает портретное и горизонтальное расположение, сенсорную крестовину и одновременные кнопки B (бег/огонь) и A (прыжок). Ручная игра загружает оригинальный ROM с домашнего сервера и начинает с его титульного экрана либо восстанавливает локальное сохранение. START передаёт нажатие кнопки NES: запускает игру с титульного экрана и переключает родную паузу в уровне. SELECT переключает 1 PLAYER GAME / 2 PLAYER GAME в оригинальном меню. В режиме двух игроков один экранный пульт управляет персонажем, чья сейчас очередь. На компьютере: стрелки, Z — B, X или пробел — A, Enter/P/Escape — START, Shift — SELECT. Самодельное меню настроек убрано; сбоку остаётся кнопка возврата к заданиям. Существующие три маршрута автоматического прохождения во время учебных заданий не изменены.

В горизонтальном положении видимое поле NES (240×224, без чёрного overscan) занимает доступную высоту, когда хватает ширины для боковых кнопок, и сохраняет пропорции. На узком экране поле уменьшается, чтобы кнопки оставались снаружи. В портретном положении управление находится под игровым изображением. Выделение текста, контекстное меню и масштабирование страницы блокируются только внутри ручной игры. Короткий тап передаётся минимум в один кадр NES; A/B удерживаются до отпускания пальца. Скорость эмуляции и физика игры не изменены.

В ручном режиме звучит полный оригинальный APU, включая музыку, эффекты и звук родной паузы. Фоновая музыка и эффекты интерфейса «Умного зайчика» в этом режиме заблокированы, в том числе при поздней загрузке WAV. Музыка и настройки учебных заданий сохранены. Общий mute и громкость эффектов управляют выходом эмулятора. После потери связи или сворачивания приложение отдельно приостанавливает эмуляцию; START возобновляет её после проверки доступа и передаёт команду самой игре.

Для Safari звук повторно активируется непосредственно при входе в игру, нажатии START, клавиши или сенсорной кнопки. Там, где доступен [Audio Session API](https://www.w3.org/TR/audio-session/), выбирается тип playback; дополнительно запускается беззвучный буфер для разблокировки Web Audio. Явный mute и уровни громкости сохраняют силу. Реальный iPhone Safari не подключён для проверки; тест Chromium проверяет настоящие NES-сэмплы и восстановление suspended AudioContext.

NES-состояние автоматически сохраняется раз в 15 секунд и при выходе в IndexedDB текущего браузера отдельно для каждого игрока (ключ player:original). Прежние сохранения подготовленных уровней остаются в браузере и не перезаписываются. Состояние восстанавливается на этом же устройстве; учебный прогресс и право на 10 минут хранятся на Lenovo. При удалении данных браузера локальное NES-сохранение исчезнет.

Проверки: python3 verify-mario.py (права, лимит, повторные запросы, истечение и изоляция) и node verify-mario-browser.cjs (настоящий NES с локальными приватными файлами, оригинальное меню и родная пауза, сенсорное управление, полный звук без WAV-фона, сохранения и прекращение игры). Для синхронизации Lenovo в список FILES /usr/local/sbin/smart-bunny-sync добавлен mario-manual.js; серверная часть устанавливается отдельно с резервной копией базы.


## Математика, английский и окружающий мир

Главное меню содержит четыре предмета. Шесть прежних режимов доступны внутри «Математика» с прежними правилами и выбором длины раунда. «По учебнику» открывает математику для 2-го или 4-го класса. Английский и окружающий мир имеют такие же меню учебников.

В school-curriculum.js находятся 39 тематических групп с оригинальными заданиями по оглавлениям первых частей шести предоставленных учебников. Перечень источников и границы покрытия описаны в BOOKS.md. Фотографии и тексты учебников не публикуются. Это банк тренировок по темам оглавлений, а не электронная копия учебников.

Доступные учебники учитывают schoolClasses профиля. Для диапазона [1,2] открыт учебник 2-го класса, для [3,4] — 4-го. В каждом предмете отдельно сохраняются класс, 10/50/100 вопросов, отмеченные пройденные темы и трудности. Смешанные тренировки и работа над ошибками используют только отмеченные темы. История конкретных вопросов хранится в браузере отдельно для каждого игрока. Математика включает задачи в несколько действий и выбор способа решения, английский — короткие тексты и диалоги, окружающий мир — ситуации с наблюдениями и проверкой выводов. В длинном смешанном раунде вопросы повторяются только после исчерпания всех выбранных тем. Английские задания текстовые, аудирование пока не реализовано.

Первая верная попытка даёт один балл. После ошибки показываются правильный ответ, объяснение и правило; повтор или следующий вопрос ждут «Продолжить». Исправление со второй попытки не приносит балл. Завершённые раунды сохраняются на Lenovo и участвуют в прежней системе монет и наклеек. Проверки нового раздела выполняются командой node verify-school.cjs.
