# Все 32 уровня Super Mario Bros.

## Игровые минуты

На экране выбора смешанной миссии подсказка под кнопкой «Начать миссию» показывает число выбранных предметов и недостающие условия. Нужны ровно три предмета и минимум две темы каждого. При неполном выборе сообщение остаётся рядом с кнопкой, получает фокус и прокручивается в видимую область; при нехватке тем раскрываются соответствующие списки. После успешного запуска открывается первое задание. Порог награды и начисление минут не изменены.

Смешанная миссия по трём предметам открывает запуск на 10 минут: Юля — 16/20, Соня — 26/30 с первой попытки. При выборе 50 вопросов: Юля — 40/50 и 13 минут; Соня — 44/50 и 12 минут. Минимум две темы каждого предмета, сбалансированное число вопросов, класс соответствует профилю.

Успешные обычные тренировки дают +1 минуту за каждые 10 вопросов, без отдельного права запуска. Бонусы сохраняются на сервере и прибавляются один раз при запуске/продолжении игры. Порог — 80% для 1–2 классов, 26/30 для 3–4; исправления и повторение ошибок не засчитываются. За одну смешанную миссию нет второго обычного бонуса. Ранее выданные запуски остаются по 600 секунд; миграция не меняет профили, сохранения и паузу. Новые запуски и паузы поддерживают больше 600 секунд. Проверки: `python3 verify-mario-minutes.py`, `node verify-mario-minutes.cjs`, `python3 verify-mario.py`.

Пауза START теперь останавливает и заработанный счётчик «Осталось». Остаток вычисляется и сохраняется сервером; повторные pause/resume не добавляют время. Пауза переживает перезапуск сервера и перенос сессии на другое устройство. Администратору время по-прежнему не ограничено.

Сворачивание, потеря фокуса и выход из игры также запрашивают паузу бюджета. Для фиксации остатка на сервере нужна связь; при сетевой ошибке игра останавливается и просит START после восстановления соединения. Запросы pause/resume/heartbeat отправляются последовательно; запоздалый ответ не отменяет более свежую паузу. Возврат через START после сворачивания не ставит работающий ROM на повторную паузу.

Новая таблица mario_pauses хранит только сессию и оставшиеся секунды. Результаты игроков, сессии входа и заработанные билеты при миграции не переписываются. Проверки: `node verify-mario-pause.cjs`, `python3 verify-mario.py`, `node verify-mario-input.cjs`: час паузы, повторные операции, перезапуск, смена устройства, защита сессии, запоздалый heartbeat и продолжение после сворачивания.

В учебном режиме и ручной игре доступны миры 1–8, по четыре уровня. На учебном экране используется список миров с уровнями 1-1…8-4. Ручная игра открывается сразу, без выбора мира и уровня: продолжается сохранённое оригинальное прохождение, а если его ещё нет, появляется меню NES с началом на 1‑1. Дальше переходами управляет оригинальная игра. В самом игровом экране остаются START/SELECT, крестовина, A/B и выход к заданиям.

Для ручной игры используется прежнее личное сохранение `original` в IndexedDB. Оно не сбрасывается при обновлении или повторном входе. Старые сохранения отдельных уровней не удаляются и не подменяют оригинальное прохождение. При истечении времени сохраняется текущая игра; новый заработанный запуск позволяет продолжить её.

Права и время не меняются: свободный вход из меню — только администратору; дети входят после учебного раунда и получают 600 секунд. Повторный вход использует существующую серверную сессию и не продлевает её. Учебный прогресс, наклейки, координаты альбома и настройки музыки не мигрируются.

Учебные маршруты основаны на **tool-assisted speedrun HappyLee и Mars608**, прохождении всех уровней без пропуска миров: [TASVideos, Movie 3728](https://tasvideos.org/3728M). На экране подготовки есть ссылка с именами авторов. Входные нажатия адаптированы к JSNES 2.1.0 (начальная строка power-on FCEUX не является кадром ввода JSNES). Полная запись проверена в том же эмуляторе: 32 уровня, без гибели и пропусков.

`tool/prepare-mario-worlds.cjs` создаёт отдельное начало и последовательность нажатий каждого уровня. Состояния связаны с контрольной суммой ROM, содержат код и графику оригинальной игры и **остаются приватными в assets/emulation/routes/**, как сам ROM. Эта папка уже исключена из Git. При загрузке выбранного уровня его маршрут заново проверяется от сохранённого начала до штатного завершения. Это занимает только длительность одного уровня в ускоренной проверке, а не всех предыдущих миров.

Для обычных уровней проверяется штатная процедура финиша; для замков — касание топора, режим победы и окончание сцены с Тоадом/принцессой. Марио не достигает финиша до последнего задания. Записи TAS используют игровые трюки, поэтому на некоторых уровнях флаг проходится без обычного спуска. Во время учебного режима звучат эффекты NES и выбранная фоновая музыка зайчика; ручная игра использует оригинальную музыку и эффекты NES.

Маршруты хранятся в JSON и gzip. Современный браузер загружает gzip через DecompressionStream; для браузеров без него есть обычный JSON. В памяти сохраняется не больше четырёх проверенных уровней. При смене мира загрузка предыдущего отменяется по версии; ручной режим не может одновременно запустить учебное воспроизведение.

Подготовка (на частном компьютере):

```
node tool/prepare-mario-worlds.cjs movie.fm2 rom.nes jsnes.js private-output-directory
```

Проверки: `node verify-mario-worlds.cjs` (нужны локальные приватные ROM, JSNES и подготовленные маршруты), `node verify-mario-input.cjs`, `python3 verify-mario.py`, `node verify-audio.cjs`. Тест миров использует реальные обработчики загрузки и движения, пересоздаёт контроллеры после восстановления, проверяет 32 старта, 32 завершения, разделение движения на задания и границы раундов из 10/20/30/50/100 заданий.
