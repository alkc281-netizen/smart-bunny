# Каталог наклеек

Один источник описания — sticker-catalog.json. Команда python3 tool/stickers.py build формирует отмеченные блоки в players.js и tool/bunny-server.py. В этих блоках вручную ничего менять не требуется. Структура загрузки игры и сервер остаются самостоятельными, дополнительная библиотека не нужна.

Для каждой наклейки задаются постоянный id, имя, коллекция, правило, цена, тип миссии и путь к картинке. Идентификаторы заработанных наклеек нельзя менять, они сохранены в профилях.

Команды из папки проекта

```sh
python3 tool/stickers.py pending
python3 tool/stickers.py import gadget /полный/путь/gadget.png --source https://страница-источника/
python3 tool/stickers.py check
python3 tool/verify-stickers.py
```

Импорт копирует PNG в assets/stickers, включает запись и обновляет обе части игры. При ошибке записи изменения откатываются. Повторный импорт активной наклейки отклоняется, чтобы случайно не заменить изображение. Проверяются формат, контрольные суммы и размеры PNG. Папка assets/stickers исключена из публичного Git. Картинку устанавливают на домашний сервер вместе с обновлённым кодом. Редактирование каталога само по себе не запускает публикацию.

Для персонажа, которого ещё нет в списке, добавьте запись в sticker-catalog.json с enabled=false. Затем используйте ту же команду import. Поля mission принимают russian (две пройденные темы русского), math (сравнение и сложение) и mixed (математика и русский). Для прежней Звезды используется review и прежнее правило трёх исправлений.

Версия API rewards=catalog-v1 открывает новый каталог. Старые вкладки с rewards=characters видят свой прежний набор. Новые наклейки скрываются от старого интерфейса без удаления из базы.

В каталог подготовлены 31 дополнительный герой и злодей. Пока изображения не импортированы, записи выключены и не предлагаются для покупки. Они охватывают основной состав и ряд второстепенных персонажей мультсериалов. Это не полный перечень всех эпизодических персонажей. Список можно расширять тем же способом.

Найденные игровые источники

- https://www.spriters-resource.com/nes/chipndale/ — спрайты Чипа, Дейла, Толстопуза и игровые материалы с другими персонажами.
- https://www.spriters-resource.com/nes/chipndale/asset/74311/ — лист Story Art & Text.
- https://www.spriters-resource.com/nes/darkwing/ — Чёрный Плащ, Гусёна, Зигзаг и боссы NES-игры.
- https://spritedatabase.net/game/197 — альтернативный каталог игровых персонажей Чёрного Плаща.

Некоторые страницы Spriters Resource вернули HTTP 403. Для персонажей мультсериалов, отсутствующих в NES-играх, подходящие изображения ещё нужно подобрать. Источники в заготовках указывают на каталоги игры; команда import требует указать фактическую страницу изображения.
