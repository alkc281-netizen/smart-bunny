# Каталог наклеек

Один источник описания — sticker-catalog.json. Команда python3 tool/stickers.py build формирует отмеченные блоки в players.js и tool/bunny-server.py. В этих блоках вручную ничего менять не требуется. Структура загрузки игры и сервер остаются самостоятельными, дополнительная библиотека не нужна.

Для каждой наклейки задаются постоянный id, имя, коллекция, правило, цена, тип миссии и путь к картинке. Идентификаторы заработанных наклеек нельзя менять, они сохранены в профилях.

Команды из папки проекта

```sh
python3 tool/stickers.py pending
python3 tool/stickers.py import gadget /полный/путь/gadget.png --source https://страница-источника/
python3 tool/stickers.py check
python3 tool/verify-stickers.py
```

Импорт копирует PNG в assets/stickers, включает запись и обновляет обе части игры. При ошибке записи изменения откатываются. Повторный импорт активной наклейки отклоняется, чтобы случайно не заменить изображение. Проверяются формат, контрольные суммы и размеры PNG. Папка assets/stickers исключена из публичного Git. Картинку устанавливают на домашний сервер вместе с обновлённым кодом. Редактирование каталога само по себе не запускает публикацию.

Для персонажа, которого ещё нет в списке, добавьте запись в sticker-catalog.json с enabled=false. Затем используйте ту же команду import. Поля mission принимают russian (две пройденные темы русского), math (сравнение и сложение) и mixed (математика и русский). Для прежней Звезды используется review и прежнее правило трёх исправлений.

Версия API rewards=catalog-v1 открывает новый каталог. Старые вкладки с rewards=characters видят свой прежний набор. Новые наклейки скрываются от старого интерфейса без удаления из базы.

Включены 30 дополнительных героев и злодеев: 10 из «Чипа и Дейла» и 20 из «Чёрного Плаща». Капоне остаётся выключенным: подходящее изображение найдено, но загрузка из проверенных источников пока недоступна. Основной состав и часть второстепенных персонажей представлены; это не полный перечень всех эпизодических персонажей мультсериалов.

Источники подключённых изображений

- https://negaverse.net/the-show/characters/ — портреты персонажей «Чёрного Плаща» из мультсериала.
- https://negaverse.net/the-show/characters/s-h-u-s-h/ — Гризликов.
- https://kattthepig.wordpress.com/tag/chip-n-dale-rescue-rangers/page/2/ — кадры со спасателями, Мэнди, Нимнулом, Толстопузом и его подручными.
- https://rincondecomiquitas.blogspot.com/2019/09/chip-y-dale-al-rescate-chip-dale-rescue.html — изображение Гаечки.
- https://www.gamekyo.com/group713_40_all.html — Волкоутка, кадр NES-игры.

В каждой новой записи source указывает на страницу, sourceImage — на фактический файл. Большинство новых картинок — цветные кадры мультсериалов, а не игровые NES-спрайты. Для общих кадров frame задаёт область персонажа, removeBackground=false сохраняет исходные цвета фона. У прежних спрайтов удаление однотонного фона сохранено.

Изображения хранятся только в assets/stickers на компьютере и Lenovo; эта папка исключена из публичного Git. В репозиторий входят каталог, источники и код подключения.

Рокфор и Зигзаг МакКряк используют одобренные иллюстрации с прозрачным фоном: assets/stickers/monty-illustrated-v1.png и assets/stickers/launchpad-illustrated-v1.png. Рокфор создан через imagegen, источник Зигзага — https://www.pngaaa.com/detail/231806. Изображения предназначены для частного семейного использования и устанавливаются на Lenovo отдельно от публичного GitHub. Прежние файлы сохранены; идентификаторы, цены, миссии и условия наград не менялись. Версия имени файла предотвращает использование старой картинки из кеша браузера.
