# Музыка и звуки

В музыкальном меню десять тем. Шесть прежних SMB1 сохранены. Добавлены Character Select и Overworld из SMB2, World 1 Map и Athletic из SMB3. Автоматический выбор использует Character Select в меню, World 1 Map в альбоме, Athletic в миссиях и Overworld SMB2 в сложении и сравнении. Остальные учебные режимы сохраняют прежние темы. Ручной выбор работает на всех экранах до его изменения игроком.

Настройки отдельно для каждого профиля: автоматический/ручной выбор, выбранная тема, включение музыки, включение победной фанфары, общий выключатель и три громкости (музыка, сигналы заданий, эффекты). Они проходят через существующий авторизованный API и очередь браузера. При входе и открытии музыкального меню настройки загружаются с сервера; ответ сервера не заменяет редактирование, начатое во время загрузки. Озвучка заданий не добавляется.

При переходе на экран с той же темой сохраняется тот же AudioBufferSourceNode. Смена темы использует короткое плавное переключение. При visibilitychange/pagehide AudioContext приостанавливается, эффекты прекращаются. Возвращение возобновляет тот же источник и позицию. Если Safari требует касания после прерывания, повторное resume выполняется по жесту. Режим ручной NES исключает музыку и эффекты интерфейса зайчика; звук NES управляется его собственным контекстом.

Завершение раунда ожидает ответ сервера: Course Clear — обычный результат, World Clear — новая наклейка. При одновременных событиях выбирается один сигнал с приоритетом коллекция → наклейка → раунд. Коллекция из 30 персонажей получает World Clear и короткое текстовое поздравление. Порог рассчитывается из включённых персонажей каталога. Дополнения Дональда остаются отдельной группой и не требуются для основной коллекции.

Сервер выдаёт audioEvent только после новой записи UUID раунда. Повторная отправка не создаёт нового события или билета Марио. Клиент проигрывает только событие текущего раунда текущего игрока и не повторяет его после открытия альбома, возврата из фона или перезагрузки. При отсутствии связи обычный сигнал раунда воспроизводится один раз; последующая отправка не запускает фанфару повторно. Во время фанфары фон приглушается до 15% выбранной громкости, затем восстанавливается.

Музыкальные WAV, исходные NSF и звуковые эффекты устанавливаются только на частный сервер. В GitHub находится код и метаданные loops.json. Четыре новые записи: mono PCM16 44100 Hz, исходный темп, без цифрового перегруза. Границы полного повторения подтверждены двумя одинаковыми периодами состояния звукового драйвера; WAV повторно прочитаны и проверены по SHA-256. Первые шесть записей и их границы не меняются.

Проверки: `node verify-audio.cjs`, `python3 verify-audio.py`, `python3 verify-auth.py`, `python3 verify-public.py`, `python3 verify-achievements.py`, `node verify-achievements.cjs`.
